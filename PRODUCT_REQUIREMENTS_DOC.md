# Product Requirements Document

The canonical product requirements document for this repository is now [PRD.md](./PRD.md).

This file is intentionally kept as a compatibility pointer because older README sections, issue links, or external notes may still reference `PRODUCT_REQUIREMENTS_DOC.md`.

## Why the PRD moved

- `PRD.md` is the conventional filename contributors and reviewers expect.
- A single canonical product document prevents README, product-spec, and architecture language from drifting.
- The new PRD is written for future public release: it separates goals, non-goals, requirements, privacy boundaries, verification, launch criteria, and open questions.

## Current canonical scope

The current PRD covers:

- Product vision and problem statement
- Target users and credential workflows
- MVP scope and explicit non-goals
- Functional requirements with acceptance criteria
- Chainlink CRE, CCIP, Automation, confidential compute, and CCID architecture
- Smart contract architecture
- Credential state model
- UX and developer experience requirements
- Security and privacy requirements
- Verification plan
- Launch criteria and success metrics

See [PRD.md](./PRD.md) for the complete specification.
